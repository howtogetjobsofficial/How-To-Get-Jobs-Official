# Implementation Plan: How to Get Jobs (HTGJ) Platform

A modern, high-conversion career and employability platform designed based on the **How to Get Jobs** brand identity, the **"Applying for Jobs But not Getting Hired?"** webinar syllabus, the **Biztop** deep emerald/lime visual language, and a self-paced **Paid Masterclass**.

---

## 1. Visual & Architectural Alignment (From Uploaded Assets)

### Brand Identity & Theme
- **Logo**: Precision SVG recreation of the official **How to Get Jobs** emblem (bold "H" arch with the upward progression pathway and clean wordmark).
- **Color Palette**:
  - **Primary**: Deep Forest Teal (`#0A2E2C`, `#0D3F3B`, `#0F4C47`)
  - **Vibrant Accent**: Electric Lime Green (`#84CC16`, `#65A30D`, `#A3E635`) for high-contrast pills, CTA buttons, and status badges.
  - **Base & Neutrals**: Warm Linen/Cream Ivory (`#F8FAF8`, `#F2F6F3`, `#FFFFFF`) for crisp editorial readability without sterile cold grays.
  - **Dark Neutral**: Midnight Slate (`#0C1615`, `#132220`) for text and dark-themed hero blocks.
- **Tone**: Authoritative, empowering, practical, and recruiter-insider informed.

## 3. Technical Implementation Architecture

1. **State & Navigation**: Clean tabbed/routed state allowing seamless navigation between Home, Webinar, Masterclass, Tools, About, and Contact, with deep-linking support.
2. **Recreated SVG Vector Logo**: Exact vector match to `2nd HTGJ Logo 2.png` with crisp scaling across desktop and mobile.
3. **Webinar Registration Engine**:
   - Live RSVP state management.
   - Dynamic `.ics` calendar file download for Google/Apple/Outlook calendars.
   - Dynamic seats remaining counter and live countdown timer.
4. **Masterclass Payment & Access Modal**:
   - Interactive enrollment drawer with order summary, guarantee badge, and curriculum preview.
5. **Interactive Career Tools**:
   - In-browser ATS analysis algorithm with real-time score bar and actionable tips.
   - LocalStorage-backed job application tracker.
6. **Responsive Design**: Flawless experience across mobile, tablet, and desktop matching the Biztop card aesthetic.
